D · Domenowy profil ryzyka DOSPERT

DOSPERT 2006, 30 pozycji, skala 1–7: gotowość W, postrzegane ryzyko R i opcjonalnie korzyści B. Średnie domen liczymy według klucza. Mapowanie W → c jest autorską regułą aplikacji, a nie wynikiem DOSPERT.

Reguła
Score = Benefit − c · Risk, c = 1 − (W − 1)/6
Model bazowy
c0 = 0,8 (odpowiada W = 2,2)
Remis modelowy
|ΔScore| < 0,005 → TIE
Walidacja
12 par z puli 16 scenariuszy rekreacji
1 · Profil● odpowiedzi z przewodnika

Średnie domen

Edytuj 30 pozycji (W, R, B)
2 · Reguła
t = (W − 1)/6, c = 1 − t wariant wrażliwości: c' = 1 − √t Score(x) = Benefit(x) − c · Risk(x), Benefit, Risk ∈ [0, 1]
3 · Wybór 12 par z puli

Benefit: 0 = popołudnie bez atrakcyjności, 1 = bardzo atrakcyjne. Risk: 0 = plan przebiegnie zgodnie z oczekiwaniami, 1 = duża niepewność przebiegu; nie jest prawdopodobieństwem urazu. Próg c* = ΔBenefit/ΔRisk; para różnicuje modele, gdy c* leży między c a c0. Reguła: odrzuć |c* − c| < 0,02 i |c* − c0| < 0,02, weź do 6 par różnicujących, uzupełnij zgodnymi, a w razie braku kolejnymi różnicującymi.

Pokaż całą pulę 16 par
4 · Walidacja

Tryb sesji: uczestnik widzi pełne opisy scenariuszy, bez indeksów i predykcji.
